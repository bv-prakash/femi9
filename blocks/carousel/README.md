# Carousel Block

## Overview

The Carousel Block provides a responsive carousel/slider component for displaying multiple items in a rotating slideshow format.

## Features

- Auto-rotation with configurable interval
- Navigation controls (previous/next buttons)
- Pagination indicators
- Touch/swipe gesture support
- Keyboard navigation
- Pause on hover
- Responsive design
- Accessibility support

## Usage

The carousel block automatically initializes when added to a page. Structure your content in a table format:

| carousel |
|----------|
| Slide 1  |
| Slide 2  |
| Slide 3  |

## Variants

| Variant | Effect |
|---------|--------|
| `billboard` | Full-width homepage hero (Femi9 design). Slides keep the authored order (no shuffle). Desktop: 1440:526 slides, text from 42.5% of the width, light 56px heading, dark button with an arrow (a **bold** link), thin bar indicators at the bottom right. Mobile: image (360px) above the text. |

Each slide row is `image | heading + bold link`.
